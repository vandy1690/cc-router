Usage

Turn on automatic usage tracking
This reads your live usage straight from Anthropic. It needs one-time permission to read your Claude Code login from the macOS Keychain.
  1. Click Turn on auto usage below.
  2. macOS will pop up: "cc-router wants to use your confidential information stored in 'Claude Code-credentials' in your keychain."
  3. If it asks, type your Mac login password.
  4. Click Always Allow, not just Allow, so it never asks again.
Clicked Deny by mistake? Press Turn on auto usage again and macOS will ask once more. Your token stays on this Mac and is never logged.
How to sync
  1. In the Claude desktop app, open Settings → Usage.
  2. Read the % for Current session, Weekly all models, and Fable.
  3. Read the session's "resets in …" time and enter it too, so the countdown stays accurate.
  4. Enter each below, then Save sync.
The meter anchors to those numbers and adds your Claude Code activity on top until you sync again or the limit resets.
